# My Wallet - Expense Tracker

My Wallet is a simple expense tracker website that I created as part of my web development internship. It helps users keep track of their daily spending in one place.

## Features

- Add a new expense with its name, amount, category, and date
- View the total amount spent
- Check the number of transactions
- Filter expenses by category
- Delete an expense when needed
- Save expenses in the browser, so they remain after refreshing the page

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## What I Learned

While building this project, I practised working with HTML forms, CSS styling, JavaScript functions, event handling, and Local Storage. I also learned how to update the page dynamically when users add or delete expenses.
